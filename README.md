#Employee Management System
A simple Java project for managing employees using MySQL. The project allows you to add, update, delete, and list employees from a database.
Features

#Installation:
1.Add the MySQL connector JAR file to your project dependencies.
2.Make sure you have a MySQL server running locally and update the connection settings in GestionBBDD.java if necessary

#Clases:
Employee:
Represents an employee with the following attributes(id,name,age,flat,salary)

#GestionBBDD: 
Connects to the MySQL database.
Creates the database and Employee table if they do not exist.

Implements CRUD operations:
Add Employee – Insert new employees into the database.
Update Employee – Modify existing employee information.
Delete Employee – Remove employees from the database.
List Employees – Display all employee records.
Console Menu – Easy-to-use interactive menu for managing employees.

#Main: 
Provides a console menu for interacting with the database.
